# Gavin Sutton — Professional Website

Static professional website for Gavin Sutton AfCGI, prepared for GitHub Pages.

## Publishing

Publish the contents of this folder from the root of a GitHub repository using GitHub Pages. No build process or third-party dependencies are required.

## Updating the CV

Replace `Gavin-Sutton-CV.pdf` with the new PDF using the same filename. Existing website links will continue to work.

## Custom domain

A custom domain can be connected later through GitHub Pages settings. Do not add a `CNAME` file until the domain has been selected and ownership confirmed.
